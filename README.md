# Pawtopia – appli pour ordinateur

Fenêtre Electron qui ouvre https://pawtopia-adoptme.onrender.com.
Le site est toujours à jour : l'appli n'a presque jamais besoin d'être refaite.

Installateurs : onglet **Releases** (Windows `.exe`, Mac `.dmg`, Linux `.AppImage` / `.deb`).
Pour en publier de nouveaux : créer un tag `v1.0.1` (ou lancer le workflow « Build » à la main).
